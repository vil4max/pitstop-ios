# Changelog

Changes a Pitstop user can notice, in the user's language. The format
follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). A line is
added when a round card with a user-visible change closes (kit KIT-D-026);
at a `v` tag the owner renames `[unreleased]` to the version and date. The
file starts with the first round on the kit's round flow (RD-012), because
Pitstop has no `v` tag yet.
