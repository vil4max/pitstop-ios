# Code audit of 2026-10-10: verified findings

**Status:** verified 2026-10-15; fixes tracked in [`backlog-run.md`](backlog-run.md)

An automated read-only audit produced 86 unverified findings (43 medium,
43 low) for four slices: Domain (F1–F23), Features core (F24–F45),
Features rest (F46–F66) and UI/shared (F67–F86). Each was checked against
the code. Verdicts:

- **DEFECT**: behaviour is wrong; fixed with a test named by its requirement.
- **DEBT**: true, no behaviour is wrong; fixed unless the row says otherwise.
- **REJECTED**: false or not applicable.

The audit measured sizes against an external SwiftLint configuration (type
body 150, function 40). This project's gate is `just verify` with
`Tooling/.swiftlint.yml` (type body 300, function 80, file 400 warning), so a
size-only finding is rejected unless that gate also flags it.
